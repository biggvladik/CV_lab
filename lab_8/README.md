# Лабораторная работа №8. Восстановление дефокусированных изображений

Программа выполняет все пункты задания для цветного изображения `image.jpg`:

- выводит RGB-каналы и grayscale;
- добавляет Гауссов шум и шум соль и перец;
- моделирует дефокусирование однородной дисковой PSF радиуса `ρ=10`;
- показывает усеченную свертку и размытие краев для подавления эффекта Гиббса;
- восстанавливает изображения обратным ПФ, псевдоинверсией, методом Тихонова
  и фильтром Винера;
- полностью повторяет прямую и обратную задачи для обоих типов шума;
- завершает работу визуальным сравнением методов без численных метрик.

## Запуск в PyCharm

Откройте `lab8/main.py` и нажмите **Run 'main'**. Рисунки открываются строго
по порядку. Следующее окно появляется только после закрытия текущего.

Все рисунки также сохраняются в папку `lab8/results`.
